FAQ

Perguntas frequentes.

Posso importar um projeto do GitHub?

Sim. A plataforma poderá importar o projeto de um repositório e criar uma cópia no workspace do bot.

Posso enviar um ZIP?

Sim. O projeto poderá ser enviado em ZIP e seus arquivos serão extraídos para o workspace.

Posso editar meus arquivos pelo site?

Sim. O painel terá um gerenciador e editor de arquivos para o projeto.

Onde meu bot será executado?

Os bots serão executados pela infraestrutura de hospedagem da Zyphor Cloud.
